# The Vercel Production variables the site needs at runtime (ship-loop ruling R29).
# Before the merge, the ship runs scripts/vercel-env-check.ps1 against this list;
# any "required" name missing from `vercel env ls production` stops the ship.
#
# Every env name the site's code reads (process.env.* outside tests) and every
# name in conestruct/site/.env.example is on one of these lines;
# tests/test_vercel_env_check.py fails on a name that is on neither.  Each line:
#   required|not-required  NAME  cite(s) -- why
# A cite is <file>:<line>, the file relative to conestruct/site/; at least one of a name's cites
# is a line that contains the name.  The Clerk variables are read by
# @clerk/nextjs itself, not by our code, so their name-bearing cite is
# .env.example; the Clerk wiring that reads them is cited beside it.
