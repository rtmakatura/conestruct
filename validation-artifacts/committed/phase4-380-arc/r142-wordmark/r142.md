# R142: the Mapbox wordmark is always shown

Light lane. Before = production at `4fd2763` (main); after = a local stack of
`r142-mapbox-wordmark`; both with `wordmark.cjs`, the picker on its default **satellite** style
(`mapbox/satellite-streets-v12`), N Broadway SB.

**The change:** one top-level rule in `globals.css`,
`.mapboxgl-ctrl:has(> .mapboxgl-ctrl-logo) { display: block !important; }`. Mapbox GL JS hides its
logo control with an inline `display: none` when the style data says `mapbox_logo: false`
(`../mapbox-wordmark.md`); a stylesheet `!important` outranks a non-important inline style, at
every width. The logo itself isn't restyled or resized (exempt from rule 163's 44 px, R142).

| | Mapbox asked for (inline) | Page shows (computed) | Wordmark box |
|---|---|---|---|
| Before, 1440 | `display: none;` | none | 0 × 0 |
| Before, 360 | `display: none;` | none | 0 × 0 |
| **After, 1440** | `display: none;` | **block** | **88 × 23**, inside the map |
| **After, 360** | `display: none;` | **block** | **88 × 23**, inside the map |

**Also fixed here (R138 regression, found in these screenshots):** at 360 the 44 px attribution
toggle drew its 24 px "i" icon tiled four times (`before-wordmark-map-360.png`); Mapbox's own rule
sets no `background-repeat` because its icon was the button's size. `background-repeat:
no-repeat` added to `.picker-map .mapboxgl-ctrl-attrib-button`; it draws once
(`after-wordmark-map-360.png`).

Guard: `components/mapbox-wordmark.test.ts` (3 tests: the rule is top-level and unique, the
toggle doesn't tile, nothing styles or hides `.mapboxgl-ctrl-logo`).
