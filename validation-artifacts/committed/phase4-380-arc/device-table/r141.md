# R141: the device schedule at the phone width (Phase 4 branch 3)

Before = production at `4fd2763` (main); after = a local stack of `phase4-device-table` (stacked
on `r142-mapbox-wordmark`). Both with `results-shots.cjs`: N Broadway SB, shoulder work, Generate,
**all 10 disclosures open**, at 1440×1000 and 360×800.

## The change

- **Phone width (≤ 480 px), option A as ruled:** each device is one block: the name and the
  quantity ("QTY") on the first line, the labelled MUTCD code under the name, then the function.
  The header row stays for screen readers, visually hidden; the table keeps explicit roles
  (`table`/`rowgroup`/`row`/`columnheader`/`cell`) because changing a row's display drops the
  implicit ones in some browsers; the visible "MUTCD"/"QTY" labels are `aria-hidden`.
- **MUTCD codes never break**, at any width (`white-space: nowrap` on the code cell).
- **The nested-frame fix (phone-only CSS):** inside the results disclosures, reference chips lose
  their side borders and side padding at ≤ 480 px and read as full-width sections between rules.
  `.disc-panel`'s own padding is untouched (DisclosureRow is shared with the pricing card), and
  reference chips render only in the results disclosures, so nothing outside them changes; it
  stays in this branch per R141.
- **Desk:** unchanged.
